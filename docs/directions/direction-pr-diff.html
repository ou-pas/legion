Le diff et le brouillon de PR au même endroit

Exploration du 05/09 · trois dispositions · tokens Atelier / Nord tels quels, rien d'inventé

Aujourd'hui la livraison se lit en deux vues du rail : Diff (arbre, fichiers, pré-revue) et PR (le pr.md de l'agent, l'état de fusion, le bouton qui crée). On ne crée pas une PR sans l'avoir lue, mais on la lit sans voir ce qu'elle change. Les trois variantes ci-dessous rapprochent les deux ; la tâche, la branche et les fichiers sont ceux de la vraie tâche #126.

Au passage : le corps de pr.md est aujourd'hui affiché en bloc de code brut. Dans les trois variantes il est rendu en markdown, comme le compte-rendu.

AUne vue « PR », lue comme une page GitHub Brouillon en tête, court. Diff dessous, long. Le rang « Diff » quitte le rail ; le bouton de création est posé juste avant les fichiers qu'il va publier. recommandée
